Module split and to-do lists

Five members, five distinct modules, one integrated menu-driven C program that tells a user whether to build solar, given their area and yearly energy use. Tick boxes save in this browser. Type each teammate's name into their module card.

What the briefing means for this plan

  1. Theme E's bullet points are suggestions, but a custom topic needs lecturer approval by Week 10. Our "build or don't build" variant reshapes Theme E (SDG 7.1), so ask the lecturer to confirm it early, in writing.
  2. The lecturer supplies a second test file on demo day. The main program must read one plain, documented CSV layout and never assume a row count or a time step. Ask the lecturer for the exact column order, header and timestamp format as early as possible.
  3. CO₂ factor is fixed: 0.758 kg CO₂/kWh, from the briefing, stored as a #define.
  4. At least 50 records and a stated data source. An hourly year is about 8,760 rows. Record where the data came from and what it is (location, irradiance type, tilt or horizontal).
  5. At least 2 key results must be recomputed in Python or MATLAB and compared with the C output. Python is the mandatory choice, and each member checks one result from their own module.
  6. Every member defends their own module in Q&A and writes an individual report (max 10 pages). Each module therefore includes its own Python check, tests and report notes.
  7. Max two groups per option, first come first served. Confirm Theme E is secured.

Shared contract (agree this in Week 10, freeze it in Week 11)

Everyone includes common.h. Only M1 edits the structs, and any change goes through the group chat. The briefing requires arrays of struct, pointer parameters, user-defined functions with return values, #define constants, switch and loops, so these prototypes already use them. Numeric values marked "assumption" are placeholders to be sourced or justified.

/* common.h */
#define CO2_KG_PER_KWH     0.758     /* grid factor from the brief */
#define MIN_RECORDS        50
#define PERF_RATIO         0.80      /* assumption: cite or justify */
#define USABLE_FRACTION    0.70      /* assumption: share of site area that can hold panels */
#define MAX_PANELS_CATALOGUE 20

typedef struct {
    int    year, month, day, hour;
    double irradiance;       /* W/m2, say whether horizontal or tilted */
    double temp_c;           /* deg C */
    int    valid;            /* 1 = numbers usable, 0 = blank/NaN/non-numeric */
} HourRecord;

typedef struct {
    HourRecord *rec;
    int         n;           /* rows kept (valid or not) */
    int         n_dropped;   /* rows dropped: unparseable timestamp */
} Dataset;

typedef struct {
    char   name[32];
    double rated_w, length_m, width_m, price_rm;
} Panel;

typedef struct {
    double area_m2;          /* site area the user can build on */
    double annual_kwh;       /* yearly energy use */
    double tariff_rm_kwh;
    Panel  panel;            /* chosen panel */
} SystemConfig;

typedef enum { VERDICT_BUILD, VERDICT_SMALLER, VERDICT_DONT } Verdict;

typedef struct {
    int     n_panels;
    double  kwp, annual_gen_kwh, offset_pct;
    double  capex_rm, saving_rm_per_year, payback_years;
    double  co2_avoided_kg;
    Verdict verdict;
} SimResult;

/* M1 loader.h */
int  load_csv(const char *path, Dataset *ds);               /* returns 0 ok, nonzero error code */
int  load_panels(const char *path, Panel out[], int max);   /* returns count loaded */
void free_dataset(Dataset *ds);

/* M2 yield.h */
double panel_area_m2(const Panel *p);
int    panels_that_fit(double site_area_m2, const Panel *p);       /* floor(usable area / panel area) */
double array_kwp(int n_panels, const Panel *p);
double annual_generation_kwh(const Dataset *d, double kwp);        /* skips valid == 0 rows */
double specific_yield(const Dataset *d);                           /* kWh per kWp per year */

/* M3 decision.h */
double  offset_pct(double gen_kwh, double use_kwh);                /* capped at 100 */
double  payback_years(double capex_rm, double saving_rm_per_year);
Verdict decide(double offset_pct, double payback_years);
const char *verdict_text(Verdict v);

/* M4 impact.h / sweep.h */
double co2_avoided_kg(double kwh);
double saving_rm(double gen_kwh, double use_kwh, double tariff);   /* capped at use */
int    sweep_panels(const Dataset *d, const SystemConfig *cfg, SimResult out[], int max);  /* loops 1..max panels */
int    best_index(const SimResult out[], int n);

/* M5 report.h / search.h */
int  write_report(const char *path, const SystemConfig *cfg, const SimResult *res);
int  export_csvs(const char *dir, const Dataset *d, const SimResult sweep[], int n);
void search_menu(const Dataset *d, const SimResult sweep[], int n);

Decisions still open

  • Who the planner is for: a household, a building or a village. This sets the scale of the numbers, the default area and the default annual energy.
  • Location and data source: pick coordinates first. NASA POWER and PVGIS both offer hourly data. Confirm the real column names and whether the irradiance is horizontal or tilted after downloading.
  • Dataset option: hourly year (recommended, about 8,760 rows) or multi-site monthly data (at least 50 rows).
  • Panel handling: the user types one panel's specs (core), or the program reads a small catalogue from panels.csv and compares panels (stretch). Specs must come from real datasheets with sources.
  • Verdict thresholds: the maximum acceptable payback and the minimum offset % for BUILD vs BUILD SMALLER vs DON'T BUILD. Cite a source or state them as assumptions in the proposal.
  • Tariff and cost values: M4 looks up a current tariff and typical installed cost per kWp, and cites the source and date in the report.
  • Battery stretch goal: in or out of scope. Treat it as optional once the core works.
  • Second-file format: ask the lecturer for a sample or the column spec. Until then the loader assumes timestamp,irradiance,temp_c with an optional header.
  • M5 carries the lightest calculations and so takes main.c, the Makefile and integration. Swap with someone if the load feels uneven.
